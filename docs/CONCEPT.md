# tabi — 旅のすべてを、これひとつで。

旅行をよくする人の旅行を、圧倒的に楽にするオールインワン旅行アプリ。

## なぜ全部入りでやるのか（データフライホイール）

計画・予約・ナビ・記録・シェアを1つのアプリに集約する最大の理由は、
**みんなの旅行計画と旅行のレビュー（日記）がすべてアプリに蓄積され、それがAIの学習ソースになる**こと。

```
条件入力 → AIがプラン提案 → 予約・購入 → 当日ナビ → 記録・アルバム → シェア・投稿
   ↑                                                            │
   └────── 実際に行った場所・滞在時間・感想・写真が次の提案を賢くする ──────┘
```

- 「計画したプラン」と「実際に歩いたルート・滞在時間」の差分が取れるのは一気通貫アプリだけ
- レビュー・日記・アルバムは属性（年齢層・用途・目的）付きのリアルな体験データになる
- 使う人が増えるほどレコメンドが当たるようになり、さらに人が集まる

## 機能マップ（フェーズ別）

| フェーズ | 機能 |
|---|---|
| 旅行前 | AI検索（条件入力）／プラン候補提案／映像でスポット確認／旅程・地図確認／予約・チケット購入 |
| 旅行中 | リアルタイムナビ（AR徒歩ナビ）／寄り道スポット提案／空き時間の自動リプラン／AIコンシェルジュ |
| 旅行後 | 旅のしおり自動生成／アルバム（写真を日付・場所で整理）／日記・レビュー／友達とシェア・投稿 |
| 海外 | 当日乗車券・交通カード購入／eSIM購入／翻訳・両替レート・緊急連絡先 |

## AI検索の入力条件（実装済み・プロトタイプ）

| 条件 | UI |
|---|---|
| 旅行人数 | ステッパー（1〜9人） |
| 年齢 | 単一選択チップ（10代〜60代〜） |
| 金額（1人あたり予算） | 単一選択チップ（〜¥20,000 / 〜¥40,000 / 〜¥80,000 / ¥80,000〜） |
| 用途 | 単一選択（家族旅行・デート・ひとり旅・友達/卒業旅行・社員旅行） |
| 目的 | 複数選択（カメラ旅・思い出旅・プロポーズ・温泉・グルメ・絶景・穴場めぐり） |
| エリア | 自由入力＋提案ボタン |
| 運転有無・交通手段 | 単一選択（電車バス・車を運転・レンタカー・飛行機） |
| 絶対に行きたい場所 | 自由入力 |
| その他リクエスト | 自由記述テキスト |
| 日程 | 日付選択 |

条件入力 → **プラン候補を複数提示**（条件タグ付き）→ 選んだプランの
**交通・宿・体験・チケットをまとめて予約・購入**まで1フローで完結する。

## 予約・チケット購入のスコープ

- 国内：新幹線・宿泊・体験・拝観チケット・交通1日券
- 海外：**当日乗車券**（MRT1日券・空港エクスプレスなど、その場で買ってQR乗車）、
  アトラクションチケット、eSIM
- 購入したQRチケット・予約確認はすべて「旅のしおり」に自動集約

## プロトタイプの位置づけ

このリポジトリは静的PWAによるコンセプトプロトタイプ。プラン生成・予約はデモ用の擬似実装で、
本実装ではAI（LLM＋蓄積データ）と予約API（OTA・チケットプロバイダ連携）に置き換える。
UIイメージは `docs/` 添付のモック画像（条件入力①→プラン提案②→映像チェック③→旅程・地図④→ナビ⑤→予約・購入⑥）に準拠。
